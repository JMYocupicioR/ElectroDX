# antislop audit 001 — 2026-10-29

Scope: collapsed alert-code control in `src/components/student/StudentQuickControlHub.tsx` (legend converted to a color-dot disclosure). Nearby notification chips in the same legend.

Dials used for this screen: ENERGY 2 / RHYTHM 2 / MOTION 2, from `DESIGN.md`.

## Findings

1. **HIGH** — R-25. White count text on the amber chip (`bg-amber-500 text-white`) is 2.15:1, below AA for any text size.
2. **HIGH** — R-25. White count text on the sky chip (`bg-sky-600 text-white`) is 4.10:1, below 4.5:1 for 11px text.
3. **HIGH** — R-25 / non-text 3:1. The gray swatch on the closed button (`bg-slate-400` on white) is 2.56:1, so the "Atendido" color is hard to see in light mode.
4. **MEDIUM** — R-19. The expanded red chip still uses `animate-pulse` on a loop. Urgency is a real state, but a perpetual pulse fights MOTION 2 and the product motion rules.
5. **LOW** — R-31. Yellow chip count falls back to `actionRequiredAssignments.length` when there are no unread warning notifications, so the number can mean two different things without a label.

## Not filed

- Five status colors are the legend's job, not a stray palette (R-29 held with purpose).
- Toggle, Escape-to-close, and `aria-expanded` are present (R-26, R-32).
- Live click-through was not possible here: no browser tools, and `npm run dev` is currently failing on an unrelated parse error in `WorkshopCard.tsx`. Tests in `StudentDashboard.test.tsx` passed for the collapsed default.
